CuriousBooks API Reference

Base URL: http://localhost:5000/api

Endpoints

📚 Books API

Endpoints for listing, searching, retrieving, and (managers only) creating/updating/deleting books.

GET /books

Get all books with optional filtering and pagination.

Query Parameters

NameTypeDescription
pageintPage number (default: 1)
per_pageintItems per page, max 100 (default: 20)
category_idintFilter by category ID
genrestringFilter by genre name
min_pricefloatMinimum price filter
max_pricefloatMaximum price filter
in_stockboolOnly return books with stock > 0
sort_bystringColumn to sort by (default: popularity_score)
sort_orderstring'asc' or 'desc' (default: desc)

Response

{ "books": [{ "id": 1, "title": "...", ... }], "total": 150, "pages": 8, "currentPage": 1, "perPage": 20, "hasNext": true, "hasPrev": false }
200 OK
GET /books/featured

Get featured/popular in-stock books for homepage display.

Query Parameters

NameTypeDescription
limitintNumber of books to return (default: 4)
200 OK
GET /books/search

Search books by title, author, description, genre, or ISBN-13.

Query Parameters

NameTypeDescription

pageintPage number (default: 1)
per_pageintItems per page, max 100 (default: 20)

Response

{ "results": [...], "total": 12, "pages": 1, "currentPage": 1, "query": "hobbit" }
200 OK

🔐 Authentication API

User registration, login, token refresh/rotation, logout, and account management. Uses JWT (access ~15 min, refresh ~30 days). Auth endpoints are rate-limited.

POST /auth/register

Register a new user account. Role cannot be set via this endpoint.

Request Body

{ "email": "user@example.com", // required "password": "securepass123", // required "username": "johndoe", // required "firstName": "John", // optional "lastName": "Doe" // optional }

Response

{ "message": "User registered successfully", "user": { ... }, "accessToken": "eyJhbGci...", "refreshToken": "eyJhbGci..." }
201 Created 400 Bad Request 409 Conflict
POST /auth/login

Authenticate user and receive JWT tokens.

Request Body

{ "email": "user@example.com", "password": "securepass123" }
200 OK 400 Bad Request 401 Unauthorized
POST /auth/refresh 🔒 Refresh Token

Refresh access token and rotate refresh token. The old refresh token is revoked.

Send refresh token in Authorization header: Bearer {refreshToken}

Response

{ "accessToken": "eyJhbGci...", "refreshToken": "eyJhbGci..." }
200 OK 401 Unauthorized
GET /auth/me 🔒 Auth

Get current authenticated user's profile (includes email).

200 OK 401 Unauthorized 404 Not Found
PUT /auth/me 🔒 Auth

Update current user's profile. Allowed fields: firstName, lastName, username. Role cannot be changed.

Request Body

{ "firstName": "Jane", "lastName": "Doe", "username": "janedoe" }
200 OK 400 Bad Request 401 Unauthorized 409 Conflict
POST /auth/change-password 🔒 Auth

Change password for the current user.

Request Body

{ "currentPassword": "oldpass", "newPassword": "newpass123" }
200 OK 400 Bad Request 401 Unauthorized
POST /auth/logout 🔒 Auth

Revoke the token in the Authorization header. Optionally include refreshToken in the body to revoke both tokens in one call.

Request Body (optional)

{ "refreshToken": "eyJhbGci..." }
200 OK 401 Unauthorized

⭐ Reviews API

Create, read, update, and delete book reviews. One review per user per book. Ratings are 0–5.

GET /reviews

List reviews with optional filtering. Filtering by user_id requires auth and is limited to own user or admin.

Query Parameters

NameTypeDescription
pageintPage number (default: 1)
per_pageintItems per page (default: 20)
book_idintFilter by book ID
user_idintFilter by user ID (auth required; own id or admin)
200 OK 401 Unauthorized 403 Forbidden
GET /reviews/{id}

Get a single review by ID (includes book).

Path Parameters

NameTypeDescription
idintReview ID required
200 OK 404 Not Found
GET /reviews/book/{bookId}

Get all reviews for a specific book with average rating.

Query Parameters

NameTypeDescription
pageintPage number (default: 1)
per_pageintItems per page (default: 10)
200 OK 404 Not Found
POST /reviews 🔒 Auth

Create a new review for a book.

Request Body

{ "bookId": 123, // required "rating": 4.5, // required, 0-5 "text": "Great book!" // optional (or "comment") }
201 Created 400 Bad Request 404 Not Found 409 Conflict
PUT /reviews/{id} 🔒 Auth

Update an existing review (owner only). Body may include rating and/or text/comment.

200 OK 400 Bad Request 403 Forbidden 404 Not Found
DELETE /reviews/{id} 🔒 Auth

Delete a review (owner only).

200 OK 403 Forbidden 404 Not Found

🛒 Orders API

Cart validation, checkout, order history, and Stripe payment. Status flow: Pending → Paid → Shipped → Delivered (or Cancelled from Pending).

GET /orders 🔒 Auth

Get order history for current user with pagination.

Query Parameters

NameTypeDescription
pageintPage number (default: 1)
per_pageintItems per page (default: 20)
statusstringFilter by status (Pending, Paid, Shipped, Delivered, Cancelled)
200 OK 401 Unauthorized
GET /orders/{id} 🔒 Auth

Get a single order by ID including line items (owner only).

Path Parameters

NameTypeDescription
idintOrder ID required
200 OK 403 Forbidden 404 Not Found
POST /orders/cart/validate

Validate cart items — check stock and calculate totals (8% tax). No auth required.

Request Body

{ "items": [ { "bookId": "123", "quantity": 2 }, { "bookId": "456", "quantity": 1 } ] }

Response

{ "valid": true, "items": [{ "bookId": ..., "unitPrice": ..., "subtotal": ..., "available": ..., "valid": ... }], "subtotal": 45.98, "tax": 3.68, "total": 49.66, "errors": null }
200 OK
POST /orders/checkout 🔒 Auth

Create a Pending order from cart items. Validates stock, creates order, reduces inventory.

Request Body

{ "items": [ { "bookId": "123", "quantity": 2 } ] }
201 Created 400 Bad Request 404 Not Found
POST /orders/{id}/pay 🔒 Auth

Mark a Pending order as Paid (mock payment). Prefer Stripe endpoints for real payments.

200 OK 400 Bad Request 403 Forbidden
POST /orders/{id}/cancel 🔒 Auth

Cancel a Pending order and restore inventory.

200 OK 400 Bad Request 403 Forbidden
GET /orders/stripe/config

Get Stripe publishable key for the frontend. No auth required.

Response

{ "publishableKey": "pk_test_..." }
200 OK
POST /orders/stripe/create-intent 🔒 Auth

Create a Stripe PaymentIntent for checkout. Validates stock and applies state-based tax.

Request Body

{ "items": [ { "bookId": "123", "quantity": 2 } ], "customerEmail": "customer@example.com", "customerName": "John Doe", "shippingAddress": { "line1": "123 Main St", "line2": "Apt 4B", "city": "New York", "state": "NY", "postalCode": "10001", "country": "US" } }

Response

{ "clientSecret": "pi_xxx_secret_...", "paymentIntentId": "pi_xxx", "amount": 49.66, "currency": "usd" }
200 OK 400 Bad Request 404 Not Found 500 Stripe Error
POST /orders/stripe/confirm 🔒 Auth

Confirm a succeeded Stripe payment and create a Paid order with shipping details. Reduces inventory.

Request Body

{ "paymentIntentId": "pi_xxx", // required "items": [ { "bookId": "123", "quantity": 2 } ], "customerEmail": "customer@example.com", "customerName": "John Doe", "shippingAddress": { "line1": "123 Main St", "city": "New York", "state": "NY", "postalCode": "10001", "country": "US" } }
201 Created 400 Bad Request 403 Forbidden 500 Stripe Error
POST /orders/stripe/webhook

Stripe webhook for payment events. Verifies signature when STRIPE_WEBHOOK_SECRET is set. Handles payment_intent.succeeded and payment_intent.payment_failed.

Expects Stripe-Signature header and raw event payload from Stripe.

200 OK 400 Bad Request 500 Stripe Error

💡 Recommendations API

Book recommendations using popularity heuristics and, when RECOMMENDER_ENABLED, ML models (content-based TF-IDF, collaborative filtering, hybrid).

GET /recommendations

Get general in-stock recommendations based on popularity.

Query Parameters

NameTypeDescription
limitintNumber of recommendations (default: 8)
excludeint[]Book IDs to exclude (repeatable query param)

Response

{ "recommendations": [...], "algorithm": "popularity", "personalized": false }
200 OK
GET /recommendations/personalized 🔒 Auth

Get personalized recommendations based on the user's reviews and purchases. Uses ML hybrid when enabled; otherwise genre/category heuristics.

Query Parameters

NameTypeDescription
limitintNumber of recommendations (default: 8)
200 OK 401 Unauthorized
GET /recommendations/similar/{bookId}

Get books similar to a specific book (content-based when ML enabled; otherwise genre/category/author heuristics).

Path Parameters

NameTypeDescription
bookIdintBook ID required

Query Parameters

NameTypeDescription
limitintNumber of similar books (default: 4)
200 OK 404 Not Found
GET /recommendations/search-based

Get recommendations based on a search query context (content-based when ML enabled; otherwise search/popularity heuristics).

Query Parameters

NameTypeDescription
qstringSearch query context
limitintNumber of recommendations (default: 4)
excludeint[]Book IDs to exclude (repeatable query param)
200 OK
